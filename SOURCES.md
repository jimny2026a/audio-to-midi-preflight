# Sources and limits

Checked on 2026-09-24:

- https://mp3tomidiflow.com/ — published input list, byte/duration limits and scope. These are site declarations; this repository does not claim to have tested every format.
- https://mp3tomidiflow.com/about — single-file workflow, Basic Pitch attribution, output scope and manual-correction caveats.
- https://mp3tomidiflow.com/privacy — declares local audio processing, but still describes a local preview and unfinished hosting arrangements. This stale language prevents treating it as an independently audited statement about current hosting.
- https://mp3tomidiflow.com/contact — says the intended contact mailbox is not verified. Do not use that mailbox for private recordings or promise support availability.
- https://github.com/spotify/basic-pitch-ts — upstream browser audio-to-MIDI library. This toolkit does not include its implementation, model or license grant.

The PCM16 report is computed from local file bytes. The checklist is original workflow guidance derived from the stated conversion limits. No accuracy percentages, speed comparison, traffic estimate, endorsement, SEO benefit or indexing deadline has been measured or promised.
